Build a premium, minimal, modern single-page website for **EXTAPANO WEB STUDIO (EWS)**.

You are the implementation agent. Build the website fully in Replit, including the UI, interactions, animations, responsive behavior, and polished visual details.

## 1. Core requirement — NO SCROLL

This is a **single-screen website**.

The main experience MUST fit inside the viewport at 100vh.

There must be:

* NO vertical page scrolling
* NO long landing-page sections stacked vertically
* NO traditional scrolling sections
* NO oversized content that pushes the viewport height

All detailed information must be revealed through:

* animated overlays
* modal windows
* expandable panels
* side drawers
* tabbed interfaces
* hover interactions
* subtle transitions

The homepage itself should remain visually calm and uncluttered.

The website should feel like a premium digital studio website rather than a pricing/catalog website.

# 14. ANIMATIONS

Use refined motion throughout the experience.

On initial load:

* EWS logo fades/reveals
* navigation appears smoothly
* hero typography reveals line-by-line
* subtle background/grid animation

Interactions:

* navigation underline animation
* buttons shift subtly on hover
* arrows animate
* modal transitions use smooth opacity + transform
* cards/panels transition smoothly
* cursor interactions can subtly affect a decorative element

Keep animation duration approximately 200–700ms depending on interaction.

Do NOT use:

* excessive bouncing
* flashy transitions
* spinning UI
* distracting parallax
* unnecessary animation everywhere

The feeling should be **expensive, calm and precise**.

Respect `prefers-reduced-motion`.
